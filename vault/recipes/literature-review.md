# Systematic literature review

> [!abstract] Goal
> Turn a research question into a synthesized, properly cited literature review.

[Back to Recipes](index.md)  ·  [Skill Index](../index.md)

## Pipeline

```mermaid
flowchart LR
  A[Question] --> B[Search] --> C[Screen] --> D[Synthesize] --> E[Cite] --> F[Write]
```

## Steps

1. **[research-lookup](../notes/literature-discovery/research-lookup.md)** / **[paper-lookup](../notes/literature-discovery/paper-lookup.md)** — search across PubMed, arXiv, Crossref, Semantic Scholar, etc.
2. **[lit-synthesizer](../notes/literature-discovery/lit-synthesizer.md)** — synthesize results into a structured report with a citation graph. Full pipeline: **[literature-review](../notes/literature-discovery/literature-review.md)**.
3. **[citation-management](../notes/research-writing/citation-management.md)** / **[pyzotero](../notes/research-writing/pyzotero.md)** — verify and manage references (BibTeX/Zotero).
4. **[scientific-writing](../notes/research-writing/scientific-writing.md)** — write the review in flowing prose.

## Ingest & summarize

- **[defuddle](../notes/literature-discovery/defuddle.md)**, **[markitdown](../notes/documents-office/markitdown.md)**, **[liteparse](../notes/documents-office/liteparse.md)** — pull clean text from web pages and PDFs.
- **[pubmed-summariser](../notes/literature-discovery/pubmed-summariser.md)** — quick briefings for a gene or disease term.
