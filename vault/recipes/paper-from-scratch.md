# Paper from scratch

> [!abstract] Goal
> Take a research idea to a submission-ready, internally reviewed manuscript.

[Back to Recipes](index.md)  ·  [Skill Index](../index.md)

## Pipeline

```mermaid
flowchart LR
  A[Idea] --> B[Research] --> C[Draft] --> D[Figures] --> E[Review] --> F[Revise + submit]
```

## Steps

1. **[idea-evaluator](../notes/reasoning-ideation/idea-evaluator.md)** — pressure-test novelty / feasibility before committing.
2. **[deep-research](../notes/academic-pipelines/deep-research.md)** — evidence gathering and synthesis. Lighter: **[literature-review](../notes/literature-discovery/literature-review.md)**.
3. **[academic-paper](../notes/academic-pipelines/academic-paper.md)** — draft the manuscript. Section-level prose: **[scientific-writing](../notes/research-writing/scientific-writing.md)**.
4. **[nature-figure](../notes/academic-pipelines/nature-figure.md)** / **[scientific-visualization](../notes/research-writing/scientific-visualization.md)** — submission-grade figures.
5. **[academic-paper-reviewer](../notes/academic-pipelines/academic-paper-reviewer.md)** — multi-reviewer critique. Also: **[peer-review](../notes/research-writing/peer-review.md)**, **[pre-submission-reviewer](../notes/research-writing/pre-submission-reviewer.md)**.
6. **[nature-response](../notes/academic-pipelines/nature-response.md)** — point-by-point rebuttal; **[venue-templates](../notes/research-writing/venue-templates.md)** for formatting.

## One-shot orchestrator

- **[academic-pipeline](../notes/academic-pipelines/academic-pipeline.md)** — runs research → write → review → revise end-to-end.
