# build-complexheatmaps

> [!info] What it does
> Build, debug, and polish ComplexHeatmap figures in R, including HeatmapList sizing, unequal-row multi-panel layouts, row and column annotations, anno_mark labels, shared legends, title decoration, spacing, and vector or raster export. Use when creating or fixing ComplexHeatmap heatmaps, especially publication figures with multiple matrices, variable row counts, annotated genes, or compressed panels.
