# design-md-library

> [!info] What it does
> Library of 74 ready-to-use DESIGN.md files — complete design systems (color tokens, type scale, components, layout, motion, do's/don'ts) reverse-engineered from real product and brand websites like Stripe, Linear, Vercel, Notion, Apple, Tesla, WIRED, and Nintendo-2001. Use when a UI task names a reference brand or an aesthetic ("make it look like Linear", "Stripe-style landing page", "premium automotive dark theme"), when you need a concrete token set to start a design system from, or when a project asks for a DESIGN.md. Vendored from VoltAgent/awesome-design-md.
